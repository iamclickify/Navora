# data/processed/

Holds intermediate outputs generated by backend ingestion and feature-engineering scripts.
These files are **gitignored** — regenerate them by running the relevant scripts.

| File | Generated By | Used By |
|------|-------------|---------|
| `model_features.csv` | `build_features.py` | Training pipeline only — not used by the live API |
| `port_observations.csv` | `generate_congestion_proxy.py` | `build_features.py` during training |

## Runtime Note
The live API server does **not** read any files from this directory.
All live data comes from the APIs (Open-Meteo, FRED/EIA, yfinance) or from
`data/historical_freight_data.csv` (root-level, kept in git).
